# Glosario y recursos

## Términos esenciales

| Término | Significado en estos apuntes |
| --- | --- |
| CMS | Sistema para gestionar contenidos. |
| Sitio web | Conjunto organizado de páginas y recursos. |
| Frontend | Parte que consulta y utiliza el visitante. |
| Backend | Panel de gestión utilizado en las prácticas. |
| Catálogo | Conjunto organizado de productos y sus datos. |
| Categoría | Agrupación de productos que facilita localizarlos. |
| Atributo | Opción que puede distinguir variantes, como talla o color. |
| Combinación | Variante concreta de un producto. |
| Tema | Componentes que definen la presentación de la tienda. |
| Módulo | Componente que incorpora o modifica funciones. |
| Máquina virtual | Ordenador simulado que se ejecuta dentro de otro. |
| Anfitrión | El ordenador real que ejecuta la máquina virtual. |
| Invitado | El sistema que funciona dentro de la máquina virtual. |
| OVA | Archivo utilizado para distribuir la máquina preparada. |
| localhost | El equipo desde el que se abre la dirección. |
