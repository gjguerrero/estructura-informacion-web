# Actividades de práctica

Estas actividades son una propuesta para acompañar las demostraciones. El profesor concretará cuáles se realizan en clase y sus condiciones. No establecen una rúbrica ni una entrega evaluable.

## 1. Reconocer las dos caras de la tienda

**Objetivo:** distinguir la administración del resultado que consulta el cliente.

1. Abre el frontend y el backend en pestañas diferentes.
2. Localiza un producto de ejemplo en ambos.
3. Identifica su nombre, precio, categoría e imagen.
4. Compara qué información puedes consultar y qué información puedes editar.

**Comprobación:** explica por qué entrar como administrador no equivale a entrar como cliente.

## 2. Organizar el catálogo de Costa Sur

**Objetivo:** aplicar una estructura comprensible antes de añadir productos.

1. Propón tres categorías para la tienda.
2. Justifica sus nombres desde el punto de vista del cliente.
3. Crea las categorías siguiendo la demostración.
4. Comprueba dónde se muestran y cómo se llega a ellas.

**Comprobación:** un compañero debe poder indicar dónde buscaría una camiseta sin que le expliques la clasificación.

## 3. Crear una ficha y sus variantes

**Objetivo:** separar descripción, características y opciones de compra.

1. Prepara el nombre y la descripción de una camiseta ficticia.
2. Decide a qué categoría pertenece.
3. Añade sus características y una imagen de práctica.
4. Sigue la demostración para incorporar variantes de talla y color.
5. Guarda y revisa la ficha desde el frontend.

**Comprobación:** identifica qué datos son comunes al producto y cuáles pueden depender de una variante. Revisa la correspondencia entre la opción elegida y la información mostrada.

## 4. Recorrer la tienda como cliente

**Objetivo:** detectar problemas de información y navegación.

1. Busca el producto desde la portada.
2. Abre su ficha y revisa si puedes resolver las dudas sobre talla, composición y disponibilidad.
3. Añádelo al carrito y comprueba la información mostrada.
4. Anota dos mejoras concretas y aplícalas siguiendo las indicaciones del profesor.
5. Guarda, recarga la tienda y comprueba el resultado.

**Comprobación:** describe cada mejora mediante una necesidad del usuario, por ejemplo «añadir las medidas para que pueda comparar tallas».

## Registro del trabajo

Puedes anotar el cambio realizado, el motivo y cómo has comprobado su resultado. Una captura puede servir como evidencia cuando el profesor la solicite.

Antes de cerrar, sigue la [rutina de final de clase](../preparacion/cada-clase.md).
