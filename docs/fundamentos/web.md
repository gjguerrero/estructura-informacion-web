# 1. La web y la información

## Una página y un sitio web

Una **página web** es un documento que podemos consultar con un navegador. Puede mostrar texto, imágenes, enlaces y formularios. Un **sitio web** reúne páginas y recursos relacionados bajo una organización común.

La página de una camiseta, la página de contacto y la página de una categoría pertenecen al mismo sitio de Costa Sur. Cada una tiene una finalidad y una dirección propia.

Un enlace permite pasar de una página o recurso a otro. Los menús, las fichas de producto y las rutas de navegación ayudan a entender dónde estamos y qué podemos hacer a continuación.

## Lo que ocurre al abrir una página

El **navegador** solicita un recurso. El **servidor** responde con los datos necesarios y el navegador presenta el resultado. Una página puede necesitar varias solicitudes para cargar imágenes, estilos u otros elementos.

La **URL** identifica la dirección del recurso. El **dominio** es el nombre que usamos para localizar el sitio. No es lo mismo que el servidor que guarda o genera su contenido.

| Elemento | Ejemplo en la tienda |
| --- | --- |
| Navegador | Firefox en el portátil de una clienta. |
| Servidor | El equipo que recibe la petición de la ficha de una camiseta. |
| Página | La ficha que presenta esa camiseta. |
| URL | La dirección concreta de la ficha. |
| Base de datos | El lugar donde la aplicación puede guardar precio, existencias y descripción. |

## Contenido, presentación y comportamiento

Podemos distinguir tres responsabilidades habituales. **HTML** estructura el contenido, **CSS** define su presentación y **JavaScript** permite añadir comportamiento en el navegador.

No necesitamos programar esos lenguajes para gestionar el catálogo con un CMS. Sí necesitamos entender que cambiar un texto, cambiar el aspecto de una ficha y cambiar el funcionamiento del carrito son tareas distintas.

> **Ejemplo.** Corregir «algodón» en una descripción modifica el contenido. Cambiar el color del botón modifica la presentación. Actualizar el total del carrito al cambiar la cantidad modifica su comportamiento.

## Páginas estáticas y contenido generado

Una web puede servir páginas preparadas de antemano o generar contenido a partir de datos cuando llega una petición. También puede combinar ambos enfoques.

Una tienda necesita mostrar información que cambia. El precio, las existencias y el contenido del carrito pueden ser distintos entre usuarios o momentos. Unos apuntes, en cambio, pueden publicarse como páginas estáticas y regenerarse cuando el profesor cambia el contenido.

## Organizar antes de publicar

Una web no mejora simplemente por contener más información. La información debe tener una finalidad, un nombre comprensible y un lugar que el usuario pueda encontrar.

En Costa Sur, «Camisetas» ayuda a localizar productos. «Cosas», «Varios» y «Otros 2» obligan al visitante a adivinar. Una estructura útil parte de las preguntas de las personas, por ejemplo «¿hay de mi talla?» o «¿cómo cuido este tejido?».
